# Islamic Content Verification Guidelines (YMYL Compliance)

Target Word Count: 500–800 words.

### Strict Verification Protocols
1. **Source Authenticity**:
   - Quranic Verses: Must cite Surah name and Ayah number (e.g., সুরা আল-বাকারা, আয়াত ১৮৫).
   - Hadith: Must cite standard Hadith collection and grading (Sahih Bukhari, Sahih Muslim, Sunan Abu Dawud, Jami` at-Tirmidhi, etc.).
   - Never quote unverified folk tales, weak (da'if) narrations without qualification, or fabricated (mawdu') texts.
2. **Standard Terminology**:
   - Arabic script with correct diacritics where applicable.
   - Standard Bengali phonetics and accurate Bengali meaning.
3. **Neutral Fiqh Context**:
   - For issues with jurisprudential differences (যেমন তারাবির রাকাত বা মোনাজাতের আদব), state majority scholar views respectfully and advise readers to consult local accredited Islamic scholars (বিজ্ঞ মুফতি/আলেম).
4. **Mandatory YMYL Disclaimer**:
   - Every Islamic knowledge and Dua record must include the standard verified source disclaimer.
